# Krotitelé nábytku - agent instructions

This repository contains the public website for Krotitelé nábytku.

Before making content, SEO, or structural changes, read:

- `docs/PROJECT_CONTEXT.md`
- `docs/BRAND.md`
- `docs/CURRENT_STATE.md`
- `docs/DECISIONS.md`
- `docs/HISTORY.md`

## Important rules

- Work from the current repository state; do not overwrite newer changes with an older local copy.
- Preserve `CNAME` and the clean-URL structure documented in `README.md`.
- Never invent an attribution, designer, manufacturer, date, provenance, or technical restoration claim.
- If attribution is uncertain, say so explicitly.
- Any photo prepared for publication must be stripped of EXIF/GPS metadata.
- Czech customer-facing copy should sound natural, restrained, and human.
- In social posts and emails use a short hyphen `-`, not an em dash.
- Avoid generic AI-style phrases and banned brand phrases listed in `docs/BRAND.md`.
- Do not publish private operational data, customer names, pending deals, internal cash-flow figures, or unpublished pricing logic in this public repository.
- If current operational context is needed and is not in the repo, ask the user rather than guessing.
